# CryptoPro Deployment

Установка и штатная переустановка КриптоПро CSP 5.0.13820 KC1 и Browser plug-in 2.0.15820 на Windows. Требуется Windows PowerShell 5.1 x64 и права администратора.

## Установщик

По умолчанию используется `\\vfs01\soft\Programs\crypto pro\CryptoPro-5.0.13820.exe`. Можно положить оригинальный EXE в `Installers` или передать `-InstallerPath`. EXE в архив и Git не включён. Проверяется Authenticode и имя издателя; SHA256 записывается в журнал. Ограничьте запись в сетевой каталог и локальный каталог ProgramData администраторами и SYSTEM.

## Локальный запуск

```powershell
.\Install-CryptoPro.ps1
.\Reinstall-CryptoPro.ps1
.\Get-CryptoProInfo.ps1
```

Переустановка выполняется штатным параметром `-reinstall`, без предварительного удаления продукта. Не используются cspclean, CSPDELETEKEYS и очистка лицензии. Это не гарантия сохранения ключей: до работ обеспечьте резервное копирование доступных для экспорта ключевых контейнеров и сертификатов штатными средствами и проверьте наличие действующей лицензии. Не запускайте на ПК с более новой версией или другим требуемым классом защиты (KC2/KC3). Скрипт рассчитан на KC1.

## Удалённый запуск

На административном ПК, вне Enter-PSSession:

```powershell
.\Deploy-CryptoProRemote.ps1 -ComputerName PC-IT-TEH
.\Deploy-CryptoProRemote.ps1 -ComputerName PC-IT-TEH -Repair
Invoke-Command -ComputerName PC-IT-TEH -FilePath .\Get-CryptoProInfo.ps1
```

Установщик и скрипт копируются через Copy-Item -ToSession. Требуются WinRM, административные права и разрешение на выполнение сценариев. Временный каталог Remote-* оставлен для диагностики; его можно удалить после завершения процесса. Перезапуск по умолчанию не выполняется. Параметр -Restart используйте только в согласованное окно работ при наличии альтернативного доступа.

## GPO

После пилотного тестирования: Computer Configuration > Policies > Windows Settings > Scripts > Startup; запуск Install-CryptoPro.ps1 в контексте SYSTEM, 64-bit PowerShell. Учетным записям компьютеров нужен доступ на чтение к скрипту и установщику (SMB и NTFS). Не ослабляйте доменную политику выполнения скриптов. Не назначайте Reinstall как постоянный Startup: он выполняет ремонт каждый запуск.

## Результаты и журналы

0 — успех или нужные версии уже установлены; 3010 — требуется перезагрузка; 1641 — установщик инициировал перезагрузку; 1 — ошибка сценария. Журналы: `C:\ProgramData\CryptoProDeployment\Logs`. Даже при коде 0 следует проверить необходимость перезагрузки и работоспособность после нее. При зависании установки проверьте процессы и MSI-журналы, не завершайте установщик принудительно без диагностики.

Лицензия проверяется вручную на рабочем столе целевого ПК, Win+R:

```cmd
control.exe "C:\Program Files\Crypto Pro\CSP\cpanel.cpl"
```

csptest -enum -info проверяет инициализацию провайдера, не срок действия лицензии. Био ДСЧ может потребовать действий пользователя; параметры подавления инициализации не применяются. Полностью безынтерактивная установка не подтверждена, поэтому массовый запуск только после пилота под SYSTEM. Не изменяйте настройки ДСЧ или класса защиты без согласования.

Параметры EXE: https://www.cryptopro.ru/forum2/default.aspx?g=posts&t=18028

Скрипты не запускались в Windows при подготовке; требуется пилотная проверка, в том числе подписи издателя, поведения EXE и журналов. Скрипты сохранены в UTF-8 BOM для PowerShell 5.1.

## Полная переустановка (Clean)

Перед запуском сохраните ключевые контейнеры и сертификаты штатными средствами, проверьте возможность восстановления и наличие действующей лицензии. Резервная копия HKLM не заменяет резервную копию ключей.

```powershell
.\Clean-Reinstall-CryptoPro.ps1 -Force
.\Deploy-CryptoProRemote.ps1 -ComputerName PC-IT-TEH -Clean
```

Сценарий проверяет установщик до удаления, экспортирует разделы реестра производителя в защищённый каталог Backup-* и удаляет Browser plug-in, затем CSP через MSI. При необходимости перезагрузки (3010) завершите её и запустите обычный Install-CryptoPro.ps1 или удалённое развёртывание без -Clean. Параметр -Restart разрешает перезагрузку, но не создаёт автоматического продолжения. Не назначайте Clean в постоянный GPO. Ручное удаление разделов производителя, ключевых контейнеров и сброс пробного срока не реализованы; безопасный перечень остаточных разделов не подтверждён. Восстановление лицензии — штатными средствами производителя. Не импортируйте резервную копию реестра целиком без диагностики. Скрипты не проверены на Windows.
